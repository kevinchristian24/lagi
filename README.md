
# Aplikasi Web Pemilah Sampah Organik dan Anorganik Berbasis AI – Kelurahan Suryatmajan

Platform web terintegrasi untuk wilayah RW 09 Suryatmajan yang menyajikan informasi profil wilayah sekaligus menyediakan fitur kecerdasan buatan (AI) untuk mengklasifikasikan sampah organik dan anorganik secara otomatis guna mendukung pengelolaan lingkungan cerdas.

## Tech Stack

**Web Framework:** Streamlit

**Frontend / UI:** Bootstrap

**Machine Learning:** Tesorflow, Transfer Learning, Vgg16

**Language:** Python

**Deployment:** Streamlit Cloud


## Run Locally

Clone the project

```bash
    git clone https://github.com/kevinchristian24/lagi.git
```

Go to the project directory

```bash
    cd lagi
```

Install dependencies

```bash
    pip install -r requirements.txt
```

Start the server

```bash
    streamlit run app.py
```
